# Orion Build Cost — UK Construction Cost Consultancy Website

A modern, responsive website for **Orion Build Cost**, a quantity surveying and construction cost consultancy targeting UK building contractors, builders, and property developers.

## Tech Stack
- **Framework**: React 18 + Vite 6
- **Routing**: React Router DOM 6
- **Styling**: Tailwind CSS 3
- **Icons**: Lucide React

## Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build & Preview
```bash
npm run build
npm run preview
```
